Card de Resumo do Pedido

Esse projeto foi feito como um exercício de HTML e CSS baseado em um desafio do Frontend Mentor.

A ideia foi criar um card de resumo de pedido seguindo o design de referência e deixando ele funcionando tanto no computador quanto no celular.

Sobre o projeto

O card representa um resumo de uma assinatura de música.

Ele possui:

- Imagem principal
- Título do pedido
- Descrição do serviço
- Plano anual
- Preço da assinatura
- Ícone de música
- Opção para alterar o plano
- Botão para prosseguir para o pagamento
- Opção para cancelar o pedido

Tecnologias usadas

- HTML
- CSS

O projeto não utiliza JavaScript.

Responsividade

Também foi feita uma adaptação para telas menores usando `@media`.

Dessa forma, o card consegue se adaptar melhor em diferentes tamanhos de tela, principalmente:

- Computadores
- Notebooks
- Celulares
